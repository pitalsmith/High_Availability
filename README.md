# Project: Kubernetes Observability & High-Availability Infrastructure

## Project Modules

* **[Standard Deployment](https://github.com/pitalsmith/High_Availability/blob/main/docs/Automated_High_Availability_Web_Architecture/README.md)**: Initial CI/CD setup, Automated High-Availability Web Architecture
* **[Blue-Green Deployment](https://github.com/pitalsmith/High_Availability/blob/blue-green-deployment/docs/Blue-Green_Deployment/README.md)**: Advanced high-availability rollout strategy with zero-downtime capabilities and instant rollback mechanics.
* **[Observability & Reliability Engineering](https://github.com/pitalsmith/High_Availability/blob/monitoring-and-observability/docs/monitoring-and-observability/README.md)**: Implementation of a full-stack monitoring ecosystem (Prometheus/Grafana) to provide deep insights into cluster telemetry. This module bridges the gap between deployment and production-grade stability, utilizing custom synthetic load-testing to validate infrastructure resilience and optimize resource allocation.
